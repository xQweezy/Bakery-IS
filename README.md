# 🍞 Информационная система управления пекарней (Bakery ERP)

Проект представляет собой десктопное приложение на базе **C# Windows Forms** и **СУБД Microsoft Access**, разработанное в рамках лабораторных работ по проектированию информационных систем.

---

## 🚀 Эволюция архитектуры проекта (Архитектурные обновления)

Проект развивался итеративно — от минимально жизнеспособного продукта (MVP) до комплексной ERP-системы автоматизации бизнес-процессов пекарни в соответствии с UML-моделями:

### 🔹 Версия 1: MVP (Минимальный жизнеспособный продукт)
* **Цель:** Обеспечить базовый прием розничных заказов кассиром.
* **Реализация в коде:** Простая форма с полями ввода данных клиента, выбором оплаты и прямой записью в таблицу `Заказы` со статусом `Выдан`.
* **Связь с UML:** Реализация базового прецедента из *Use Case* диаграммы.

### 🔹 Версия 2: Полноценная ERP-система пекарни
* **Цель:** Сквозная автоматизация производства, складского учёта и логистики кухни.
* **Реализация в коде:** 
  * Интерфейс переработан на контейнер вкладок `TabControl` (разделение ролей кассира, кладовщика и пекаря).
  * **Вкладка «Продажи»:** Добавлена динамическая витрина товаров (`dataGridViewShowcase`), подтягивающая данные из таблицы `Продукция`.
  * **Вкладка «Склад сырья»:** Интегрирована таблица `dataGridViewSklad` для контроля остатков муки, сахара и сырья из таблицы `Ингридиенты`.
  * **Вкладка «Очередь кухни»:** Интегрирован монитор заказов `dataGridViewKitchen`. Заказы теперь поступают со статусом `Новый` и ожидают выпекания.
* **Связь с UML:** Логика полностью соответствует *Activity Diagram* (движение заказа по этапам) и *Sequence Diagram* (взаимодействие интерфейса с таблицами БД при проверке остатков сырья).

## 💾 Структура базы данных (Microsoft Access)

Связь с СУБД реализована через технологию `OleDb` напрямую к файлу `bakery.accdb`. В системе задействованы ключевые сущности бизнеса:
* `Продукция` — перечень выпечки и цен (выводится на витрину).
* `Ингридиенты` — учёт сырья на складе пекарни.
* `Заказы` — регистрация продаж, способов оплаты (Карта/Наличные/QR-Код) и статусов кухни.
